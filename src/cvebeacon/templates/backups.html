A backup contains:

  • the configured state databases, including monitoring and inventory state, watch history, account records and dashboard job history;
  • other SQLite databases CVEBeacon owns in its data directory;
  • the configuration file; and
  • password and key files the configuration refers to, only when you choose to include them. Missing files and symbolic links are skipped, and the backup stops if a chosen file cannot be copied.

Dashboard-managed inventory files are not included. Copy the private inventory directory separately.

Databases are copied while CVEBeacon keeps running. Each file gets a recorded checksum; use Verify to check them.

These files are left out by default. Include them only when the backup will be stored with the same access controls as the originals.
